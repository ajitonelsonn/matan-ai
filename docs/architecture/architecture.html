⏱ Analysis step loop

The browser drives one analysis per request, so nothing is left running after a response on serverless compute.

Route handlers (/api/…)

Verified per request with aws-jwt-verify; every read and write is scoped to the Cognito sub — users never see each other's data.

🔐 Ring session

  • Token sealed (AES-256-GCM) in an HttpOnly cookie
  • Any Lambda instance can restore it

🔄 Event sync

  • Ring history ∪ stored events
  • New events marked pending

Matan AI pipeline

One awaited request: media → model → decision → storage → alert.

  • Nova Pro reads the snapshot (escalates to the clip when it helps)
  • Decision Engine — priority & action from the analysis + context
  • Smart Rules — deterministic Ignore / Monitor / Notify / Escalate

🖼 Media API

Streams S3 objects after checking they belong to the caller.

✉️ Notifier

Branded email with the analyzed frame; SES first, SMTP fallback.

Request flow

  1. 1 Signed-in request (Bearer token)
  2. 2 Sign-in / tokens via Cognito
  3. 3 Devices & event history
  4. 4 New events persisted
  5. 5 Nova Pro reads the evidence
  6. 6 Analysis + decision stored
  7. 7 Snapshot / clip into S3
  8. 8 Ring media pulled server-side
  9. 9 Notify / Escalate → SES
  10. 10 Alert email delivered
  11. 11 Media served with the token
  12. 12 Browser drives each analysis
  13. 13 Live WebRTC, browser ⇄ Ring
